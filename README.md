# LAST ISLAND

เกมยิงเอาตัวรอด 3 มิติบนเว็บ ออกแบบให้เล่นได้ด้วยเมาส์และคีย์บอร์ด หรือปุ่มสัมผัสบนมือถือและแท็บเล็ต ตัวละครและแผนที่เป็นงานต้นฉบับ

## เปิดเกมในเครื่อง

ต้องมี Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```sh
npm start
```

แล้วเปิด http://127.0.0.1:4173

## การควบคุม

- WASD / ลูกศร: เดิน
- ลากเมาส์: มองรอบตัว หรือคลิกขวาเพื่อจับเมาส์
- คลิกซ้าย: ยิง
- Shift: วิ่ง
- R: เติมกระสุน
- Q: รักษา
- E / 1 / 2 / 3: เปลี่ยนอาวุธ
- Esc: พักเกม
- มือถือ: จอยซ้ายเดิน ลากพื้นที่จอด้านขวาเพื่อมอง และปุ่มสัมผัสยิง/เติมกระสุน/รักษา/เปลี่ยนปืน

## ขอบเขตเวอร์ชันนี้

โหมดเล่นคนเดียวกับบอต 11 ตัว มี 3 อาวุธ ของเก็บ วงบีบ แผนที่ย่อ และหน้าสรุปผล ไม่มีระบบออนไลน์หลายผู้เล่น บัญชีผู้ใช้ หรือร้านค้า

ไฟล์เว็บไซต์ทั้งหมดอยู่ใน `dist/` สามารถโฮสต์แบบ static ได้ อุปกรณ์ต้องรองรับ WebGL2 และควรใช้เบราว์เซอร์ปัจจุบัน Library Three.js 0.180.0 อยู่ใน `dist/vendor/` พร้อมใบอนุญาต MIT โดยไม่มีการดึง CDN ระหว่างเล่น
