# LAST ISLAND

เกมยิงเอาตัวรอด 3 มิติบนเว็บ ออกแบบให้เล่นได้ด้วยเมาส์และคีย์บอร์ด หรือปุ่มสัมผัสบนมือถือและแท็บเล็ต ตัวละครและแผนที่เป็นงานต้นฉบับ

เวอร์ชัน 2.0 เพิ่มการร่อนลงเกาะ ตัวละครมีข้อต่อและท่าเดิน เนินหญ้า ชายฝั่ง บ้าน 12 หลังที่เข้าได้ ต้นไม้และผนังที่บังกระสุน มุมกล้องเหนือไหล่พร้อมหลบสิ่งกีดขวาง การเล็ง กระโดด ย่อตัว กำแพงป้องกัน และตัวเลขความเสียหายพร้อมโบนัสยิงศีรษะ อาวุธแต่ละชนิดมีโมเดลต่างกัน

หน้าจอการเล่นได้รับแรงบันดาลใจจากคลิปอ้างอิงที่ผู้ใช้ให้ ไม่ใช่การสร้าง Free Fire แบบเหมือนทุกพิกเซล โมเดล พื้นผิว และผังเกาะสร้างขึ้นสำหรับโปรเจกต์นี้ ไม่มีไฟล์ทรัพย์สินเกมต้นฉบับ

## เปิดเกมในเครื่อง

ต้องมี Node.js 20 ขึ้นไป ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

```sh
npm start
```

แล้วเปิด http://127.0.0.1:4173

## การควบคุม

- WASD / ลูกศร: เดิน
- เมาส์: มองรอบตัวเมื่อจับเมาส์ หรือใช้การลากหากเบราว์เซอร์ไม่รองรับ
- คลิกซ้าย: ยิง
- คลิกขวาค้าง: เล็งและซูม
- Shift: วิ่ง
- Space: กระโดด
- C: ย่อตัว / ยืน
- G: วางกำแพงป้องกัน (เริ่มต้น 3 ชิ้น อยู่ได้ 25 วินาที หรือแตกเมื่อรับความเสียหายครบ 220)
- R: เติมกระสุน
- Q: รักษา
- E / 1 / 2 / 3: เปลี่ยนอาวุธ
- Esc: พักเกม
- มือถือ: จอยซ้ายเดิน ลากพื้นที่จอด้านขวาเพื่อมอง ลากปุ่มยิงเพื่อหันและยิงพร้อมกัน พร้อมปุ่มเล็ง กระโดด ย่อ กำแพง เติมกระสุน รักษา วิ่ง และเปลี่ยนปืน รองรับการสัมผัสหลายจุด แนะนำแนวนอน

## ขอบเขตเวอร์ชันนี้

โหมดเล่นคนเดียวกับบอต 11 ตัว มี 3 อาวุธ ของเก็บอัตโนมัติ วงบีบ แผนที่ย่อ และหน้าสรุปผล เริ่มเกมด้วยการร่อนประมาณ 7 วินาที ใช้จอยหรือ WASD เลือกจุดลง ก่อนเข้าสู่การต่อสู้ ไม่มีระบบออนไลน์หลายผู้เล่น ทีม บัญชีผู้ใช้ หรือร้านค้า

กราฟิกเป็นรูปแบบ stylized ที่สร้างด้วยเรขาคณิต ไม่ใช่กราฟิกหรือแผนที่ต้นฉบับจากสองคลิป การตรวจหน้าจอผ่านเบราว์เซอร์ครอบคลุมมือถือแนวตั้ง/แนวนอน แท็บเล็ต และคอมพิวเตอร์ แต่ยังไม่ได้ทดสอบกับฮาร์ดแวร์มือถือจริงทุกประเภท

ไฟล์เว็บไซต์ทั้งหมดอยู่ใน `dist/` สามารถโฮสต์แบบ static ได้ อุปกรณ์ต้องรองรับ WebGL2 และควรใช้เบราว์เซอร์ปัจจุบัน Library Three.js 0.180.0 อยู่ใน `dist/vendor/` พร้อมใบอนุญาต MIT โดยไม่มีการดึง CDN ระหว่างเล่น
