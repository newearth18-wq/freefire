# LAST ISLAND · SEASON 05

เกมยิงเอาตัวรอด 3 มิติบนเว็บสำหรับคอมพิวเตอร์ มือถือ และแท็บเล็ต มีโหมดเล่นเดี่ยว โหมดฝึกทีมกับบอต และห้องทีมออนไลน์สำหรับเพื่อนสูงสุด 4 คน

เวอร์ชัน 3 ยกเครื่องล็อบบี้ ตัวละครพร้อมแอนิเมชัน พื้นผิวสนาม แสงเงา บ้านและโกดัง 16 หลังที่เข้าได้ มุมกล้องเหนือไหล่ การเล็งและการบังกระสุน เพิ่มระบบล้ม ชุบเพื่อน ดูเพื่อนหลังถูกกำจัด และรายชื่อสมาชิกทีม กราฟิกเป็นแนว stylized และแผนที่สร้างสำหรับ LAST ISLAND โดยอ้างอิงรูปแบบการเล่นจากคลิปที่ผู้ใช้ให้

เวอร์ชัน 4 แก้อาการกระตุกด้วยท่าประคองปืนที่คำนวณล่วงหน้า อัปเดตแอนิเมชันตามระยะและการมองเห็น เงาสภาพแวดล้อมที่เก็บใช้ซ้ำ และรวมการวาดของเก็บกับก้อนหิน ลดงานทุกเฟรม มีคุณภาพภาพ **อัตโนมัติ / เน้นลื่น / ภาพคม** ให้เลือกในล็อบบี้และเมนูพัก อัตโนมัติลดความละเอียดเมื่อเครื่องวาดภาพไม่ทัน

บอตหาเส้นทางผ่านประตูและอ้อมสิ่งกีดขวาง รวมถึงกำแพงผู้เล่น และเข้าช่วยเพื่อนที่ล้ม ทดสอบการเดินเข้าบ้านเพื่อชุบเพื่อน ปรับเวลาตอบสนองและจังหวะยิงของบอตให้มีเวลาตั้งตัว กล้องซ่อนตัวผู้เล่นเมื่อถูกผนังบีบเข้าใกล้ มีปุ่มจับเมาส์พร้อมคำแนะนำลากเพื่อมองเมื่อเบราว์เซอร์ไม่อนุญาต และเกมฝึกใช้การจำลอง 30 ครั้งต่อวินาทีแยกจากการวาดภาพ

เวอร์ชัน 5 เพิ่ม QR เชิญเข้าห้องและเครื่องสแกนด้วยกล้องหรือภาพในเครื่อง มีตัวละครต้นฉบับของ LAST ISLAND 3 แบบ (อาร์ค / โนวา / โกสต์) เลือกเสื้อ กางเกง รองเท้าแยกกัน เปลี่ยนสีเสื้อผ้า ผม สีผิว และกระเป๋า หมุนดูโมเดล 3 มิติได้ ชุดที่ใส่ส่งให้เพื่อนเห็นในห้องและในแมตช์ พร้อมบันทึกชุดล่วงหน้า 5 ช่องในเบราว์เซอร์นี้ การแต่งตัวไม่มีผลต่อพลังหรือเกราะ และยังไม่มีระบบทักษะตัวละคร

## เล่นกับเพื่อนจริง

1. เปิดเกมและใส่ชื่อผู้เล่น
2. เลือก **เล่นทีม → สร้างห้องออนไลน์**
3. ส่งรหัส 6 ตัว ลิงก์จากปุ่ม **คัดลอกลิงก์** หรือภาพจากปุ่ม **บันทึกภาพ QR** ให้เพื่อน
4. เพื่อนเลือก **เล่นทีม** ใส่รหัสแล้วกด **เข้าห้อง** หรือกด **สแกน QR เข้าห้อง** เปิดกล้อง/เลือกภาพ QR แล้วกด **เข้าห้องนี้**
5. เจ้าของห้องกด **เริ่มแมตช์** ทุกคนจะลงเกาะพร้อมกัน

เพื่อนที่เข้าห้องอยู่ทีมเดียวกัน ช่องที่ว่างเติมบอตให้ครบ 4 คน ต่อสู้กับอีก 3 ทีมบอต รวม 16 ตัวละครในสนาม โหมดเล่นเดี่ยวเป็นผู้เล่น 1 คนกับบอต 15 ตัว ยังไม่มีการจับคู่กับทีมผู้เล่นอื่น บัญชีผู้ใช้ หรือแชตเสียง

ห้องและแมตช์ออนไลน์ใช้เซิร์ฟเวอร์ร่วมกัน ตำแหน่ง ความเสียหาย อาวุธ และการชุบตัดสินที่เซิร์ฟเวอร์ สมาชิกมีโทเค็นเฉพาะตัวซึ่งไม่ส่งให้ผู้เล่นคนอื่น ห้องหมดอายุหลังสร้าง 1 ชั่วโมง โหลดหน้าใหม่แล้วกลับห้องเดิมได้ในแท็บเดิม เจ้าของห้องออกแล้วสิทธิ์เริ่มแมตช์จะส่งให้สมาชิกคนถัดไป

QR มีเฉพาะลิงก์และรหัสห้อง ไม่มีโทเค็นสมาชิก กล้องเปิดเมื่อผู้เล่นกดปุ่มและอนุญาตเท่านั้น ต้องใช้ HTTPS หรือ localhost ถ้าไม่อนุญาตกล้องยังเลือกภาพ QR ได้ ภาพอ่านในอุปกรณ์และไม่อัปโหลด กล้องหยุดเมื่อปิดเครื่องสแกนหรือซ่อนหน้าเว็บ ลิงก์เชิญรับเฉพาะเว็บเกมต้นทางเดียวกัน

## เลือกตัวละครและแต่งชุด

กด **ตัวละคร / ตู้เสื้อผ้า** ในล็อบบี้หรือ **ตัวละคร / แต่งชุด** ในห้อง เลือกหนึ่งใน 5 ช่องชุด เลือกตัวละครและหมวดเสื้อผ้า แล้วกด **ใช้ชุดนี้ & บันทึก** ชุดที่เลือกใช้กับแมตช์ถัดไปทั้งเล่นเดี่ยวและออนไลน์ ปิดหน้าต่างก่อนบันทึกจะกลับไปใช้ชุดเดิม ชุดบันทึกอยู่ในอุปกรณ์และเบราว์เซอร์ปัจจุบัน ยังไม่ซิงก์ข้ามเครื่อง การเปลี่ยนชุดระหว่างแมตช์ออนไลน์ถูกปิดไว้

## เปิดในเครื่อง

ใช้ Node.js 24 ขึ้นไป ตัวเซิร์ฟเวอร์ทดสอบใช้ SQLite ที่มากับ Node:

```sh
npm start
```

เปิด http://127.0.0.1:4173 ในหลายแท็บเพื่อทดสอบห้องออนไลน์ได้ ฐานข้อมูลทดสอบอยู่ใน `.sites-runtime/` ซึ่งไม่รวมใน Git

## การควบคุม

- WASD / ลูกศร: เดิน · Shift: วิ่ง
- เมาส์: มองรอบตัว · คลิกซ้าย: ยิง · คลิกขวาค้าง: เล็ง
- Space: กระโดด · C: ย่อตัว
- G: กำแพงป้องกัน · Q: รักษา · R: เติมกระสุน
- E / 1 / 2 / 3: เปลี่ยนปืน
- F ค้าง: ชุบเพื่อนที่อยู่ใกล้ เป็นเวลา 3 วินาที
- Esc: เปิดเมนูพัก โหมดออนไลน์ผู้เล่นคนอื่นยังเล่นต่อ
- มือถือ: จอยซ้ายเดิน ลากพื้นที่ขวาเพื่อมอง ลากปุ่มยิงเพื่อหันพร้อมยิง มีปุ่มเล็ง กระโดด ย่อ กำแพง ยา เติมกระสุน วิ่ง เปลี่ยนปืน และชุบเพื่อน รองรับหลายจุดสัมผัส แนะนำเล่นแนวนอน

เริ่มด้วยการร่อน 6 วินาที มีอาวุธ 3 ชนิด ของเก็บอัตโนมัติ เกราะ กำแพงที่ยิงแตกได้ แผนที่ย่อ และวงบีบจนจบแมตช์ เพื่อนร่วมทีมยิงกันเองไม่เสียเลือด

## ตรวจสอบและสร้างไฟล์เผยแพร่

```sh
npm install
npm run check
npm test
npm run build
```

ซอร์สเกมอยู่ใน `public/` ระบบห้องอยู่ใน `server/worker.mjs` ไฟล์สร้างเสร็จอยู่ใน `dist/client/` และ `dist/server/index.js` การโฮสต์ออนไลน์ต้องมี Cloudflare Workers-compatible runtime, binding `ASSETS` สำหรับไฟล์ `dist/client/` และ D1 binding `DB` พร้อม migration ใน `drizzle/` การโฮสต์เฉพาะไฟล์ static ใช้ได้กับโหมดฝึกเท่านั้น

Sites ใช้ project เดิมตาม `.openai/hosting.json` และ migration ที่สร้างด้วย Drizzle schema ใน `db/schema.ts` การเผยแพร่จะนำ migration ไปใช้ก่อนอัปโหลด Worker

## ทรัพย์สินและใบอนุญาต

ตัวละครและแอนิเมชันเป็น CC0 จาก Quaternius และพื้นผิวเป็น CC0 จาก Poly Haven พร้อมที่มาใน `public/models/ATTRIBUTION.md` และ `public/textures/ATTRIBUTION.md` Three.js 0.180.0 พร้อม loaders/utilities อยู่ใน `public/vendor/` ภายใต้ MIT ไม่ต้องโหลด CDN ขณะเล่น

ตัวสร้าง QR ใช้ `qrcode` 1.5.4 (MIT) และตัวอ่านใช้ `jsQR` 1.4.0 (Apache-2.0) พร้อมใบอนุญาตใน `public/vendor/` ทั้งคู่โหลดเมื่อใช้ QR เท่านั้น

เกมต้องใช้เบราว์เซอร์ที่รองรับ WebGL2 ความลื่นบนมือถือขึ้นกับอุปกรณ์และเครือข่าย การทดสอบครอบคลุมกฎเกม ระบบห้อง และการเล่นร่วมกันจากสองหน้าจอในเครื่อง ยังต้องทดสอบประสิทธิภาพกับโทรศัพท์จริง
